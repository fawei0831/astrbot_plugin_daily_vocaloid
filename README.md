# 今日术力口

AstrBot 插件：今日术力口、今日中术、今日日术。发送B站视频封面、歌名、P主、引擎和B站链接。

## 安装
在 AstrBot 插件页面从链接安装：
https://github.com/fawei0831/astrbot_plugin_daily_vocaloid

群聊 @Bot 今日术力口 / 今日中术 / 今日日术；私聊直接发送对应命令。每次一首，三个命令共享同会话推荐历史，连续168小时不重复，各群与私聊用户独立。今日日术沿用日语/外语曲池。

## 曲库
资料来源为 https://voca.wiki/ 和 https://vcpedia.cn/ 的B站殿堂曲资料。附带3832条公开歌曲元数据快照，首次安装自动解压至插件数据目录；已有数据库优先保留。封面采用B站视频图片地址，下载缓存由B站校验流程负责；无法发送图片时降级文字。

数据库不含聊天内容、群号、用户号、推荐历史或服务器本地封面路径。歌曲和图片权利归各权利人。资料来源字段保留在数据库中。没有复制歌词、音频或视频。

## 更新
在 AstrBot 插件页面更新。运行时数据库和历史保存在 data/plugin_data/astrbot_plugin_daily_vocaloid，仓库更新不会覆盖已有曲库和历史。曲库同步与B站校验由原插件管理页面/接口触发，不会每次抽歌重新搜索网站。

## 版本
2.3.5：在服务器已验证版本基础上整理为独立GitHub仓库，新增首次安装曲库初始化。今日神椿已拆为另一个插件，本插件不注册今日神椿。
